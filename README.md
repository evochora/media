# Evochora media

Media files of the [Evochora](https://github.com/evochora/evochora) project that are too large for its
repository.

- `homepage/` holds the files the homepage at [evochora.org](https://evochora.org) loads from here.
  A file in this directory is public the moment it is pushed, and renaming one breaks the page that loads it.
- `originals/` holds the sources those files were made from. Nothing loads them. They are kept so that a
  file can be produced again in another size or quality.
